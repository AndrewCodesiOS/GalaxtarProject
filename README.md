# GALAXTAR

A browser-based space survival and exploration arcade game ported from SwiftUI to HTML5 Canvas and vanilla JavaScript.

## Features
- **60 FPS Arcade Combat:** Drag/mouse/arrow-key ship control, tap/Spacebar firing, triple-tap Charge Beam, and Heat-Seeking missiles.
- **Dynamic Hostiles:** Crimson Vectors, Void Vectors, Verdant Vectors, Solar Imperators, Oblivion Frames, and Mirror Ships that copy your hull and stats.
- **Persistent Progression:** Upgrade Fuel (with Solar Charging), Shields (with Regeneration), Weapons, and Thrusters (with Warpdrive trails), and climb ranks from Star Cadet to Astral Legend.
- **Narrative & Flight Logs:** Dynamic AI/Pilot flight logs, 10 sequential story chapters unlocked every 20 runs, and a multi-page Pilot's Guide.
- **Game Modes:** Standard, Peaceful Mode, and Hardcore Mode.
- **Zero-Dependency Audio:** Synthesized ambient space soundtrack and pitch-randomized SFX via the Web Audio API (no external audio assets required).

## Hosting on GitHub Pages
1. Push this repository to GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**, select `main` and `/ (root)`, and click **Save**.
